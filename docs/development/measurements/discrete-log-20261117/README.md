# 離散対数の性能比較（2026-11-17）

## 対象と調査

比較元は main `179d99a39514b3321a163218273b394cdf7e1203` の `discrete_log`。最小非負指数、合成数、底と法が互いに素でない場合、任意の signed 64-bit 入力と `1 <= m <= INT32_MAX` の契約を保つ。[Library Checker の最速提出 #412908](https://judge.yosupo.jp/submission/412908) は位数分解、Pohlig–Hellman、Barrett、連続ハッシュを使う。ここでは独立実装し、剰余環の位数から底の正確な位数を求め、最後に候補を検算する。提出ソースの表示時間と手元の測定は環境・入力が異なり、直接比較できない。

因数分解は対象の法が最大 `INT32_MAX` のため、試し割りで最大 46340 まで調べる。小さい指数を先に調べ、短周期・部分群外の判定も行う。大きな素因数の桁の探索は連続メモリのハッシュを使用する。衝突を含むハッシュ探索の最悪計算量は期待値と異なる。ACL `internal::barrett` を使用するため、ACL内部 API への依存がある。

## 計算部分の時間

Windows x64、論理 CPU 16 にプロセスを固定。Clang 18.0.3（`--target=x86_64-pc-windows-msvc -std=gnu++20 -O2 -DNDEBUG`）、MSVC 19.43.34809（`/std:c++20 /O2 /DNDEBUG`）。入力生成と出力を時間から除き、同じバイナリ・200クエリ・固定 seed で旧実装と候補を3回ずつ交互に測定した中央値。checksum は一致。共有 CPU の他の負荷は制御しておらず、ばらつきがある。時間単位は ms。

| 入力 | Clang 旧 | Clang 新 | MSVC 旧 | MSVC 新 |
| --- | ---: | ---: | ---: | ---: |
| 法 1000000007、底・目標ランダム | 1489.81 | 94.48 | 1624.70 | 100.19 |
| 法 998244353、底・目標ランダム | 1557.14 | 12.69 | 1595.05 | 12.06 |
| 法 1000000、底・目標ランダム | 14.64 | 0.158 | 12.94 | 0.173 |
| 法 2147483647、底・目標ランダム | 2870.43 | 16.26 | 2202.73 | 16.29 |
| 法 1000000007、底 m-1・目標 m-2 | 244.67 | 0.0258 | 212.57 | 0.0234 |

先行探索の閾値 32、128、512 を、同じ生成済みクエリ2000件でそれぞれ3回測定した。指数128〜511では中央値 193.41、178.93、4.67 ms、指数1000以上では 479.08、487.46、476.62 ms。これらの分布では512が有利なため採用した。小さい時間の差はノイズの影響を受ける。

## 正答性・再現

Clang／MSVC の C++20・23 と `NDEBUG` 有無の8構成で、法 250 以下の全探索、固定 seed の2万ケース、int64両端と法の境界を旧実装と比較した。Library Checker 公式生成器 `73876f1cbcf082d2b22722924b924d3d65a2f00e` の指定 seed による20入力で旧実装・改善 BSGS・最終候補の出力が一致。公式 checker そのものの実行ではない。候補の追加テストでは、非巡回群で部分群外となる例と、2の累乗を法とする部分群で既知の位数から作った解・解なしの各630例も確認した。

生の結果、各候補とドライバ、実行コマンド、公式生成器の原本とその Apache 2.0 ライセンスを `reproducibility.tar.gz` に保存した。展開後、必要なコンパイラ・ACL のパスを `*-run.py` 内で環境に合わせて変更して実行する。旧コードと改善 BSGS は比較用であり公開 API ではない。公式ケースの実際の入出力は生成器と seed から再生成し、SHA-256 は `official-results.json` に記録している。

最速提出との同一条件での直接測定、他の CPU・GCC での性能測定、競技サイトへの提出実行時間は未測定。

独立監査では、法 3063、3027、3103、4076 で長い位数を持つ底32件について全ての目標を愚直周期と比較した。106,152件が一致し、うち16,146件は最小指数が512以上で Pohlig–Hellman に到達し、73,622件は解なしだった。実行記録とテストは `independent-audit/` に置く。
